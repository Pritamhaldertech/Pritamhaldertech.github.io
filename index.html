Featured · Bachelor's thesis, 2026

Classifying rheumatoid arthritis from synovial gene expression

Rheumatoid arthritis (RA) and osteoarthritis (OA) both damage joints but have different causes and treatments. I compared four classical ML models for telling them apart from gene expression in synovial tissue, merged from five public GEO datasets on two microarray platforms. The pipeline runs end to end from one script, and every reported number traces back to an output CSV.

93patients (52 RA, 41 OA) from 5 GEO cohorts
2,022 → 308genes after Boruta ∩ Mann-Whitney selection
98.8%nested 5-fold CV accuracy, logistic regression
5 / 5cohorts classified perfectly when held out (LODO)
  1. Data retrieval

    Downloaded GSE55235, GSE12021, GSE36700, GDS5402 and GDS5403 in R.

  2. Harmonisation

    log2(x+1), gene-symbol aggregation across GPL96/GPL570, ComBat batch correction.

  3. Feature selection

    Boruta (334 genes) intersected with Mann-Whitney U at FDR < 0.01 (599 genes) gave 308.

  4. Modelling

    Random Forest, XGBoost, SVM and logistic regression, tuned by grid search inside nested CV.

  5. Validation

    Stratified hold-out, 1,000-sample bootstrap CIs, leave-one-dataset-out, ANOVA and Welch's t-tests.

  6. Explainability

    SHAP for all four models: Tree, Kernel and Linear explainers, plus per-patient waterfall plots.

Nested CV as the headline number

Feature selection and tuning run inside each outer fold, so the reported accuracy is not inflated by leakage. The naive-vs-nested gap is at most 1.3 points.

Found and fixed a bootstrap bug

An early version reused one random seed for all 1,000 resamples, which produced zero-width confidence intervals. Each resample now draws from a fresh RandomState.

Reported a negative result as it was

A pre-registered list of 22 literature RA markers was mostly absent from the models' top SHAP genes (at best 1 of 22 in the top 20). I documented this rather than tuning until it looked better.

Built to be rerun

R handles retrieval and batch correction; a six-stage Python pipeline runs from one entry point. Seeds are fixed at every seedable step, and older scripts are archived for an audit trail.

Limitations. The cohort is small (93 patients, 17 in the hold-out set), so the 100% scores should be read with care. The leave-one-dataset-out check is the strongest evidence that the signal is real and not a batch artifact. The code is private while the thesis is under assessment and is available on request.
